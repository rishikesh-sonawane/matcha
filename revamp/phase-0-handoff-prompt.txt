CONTEXT

Naukri, RemoteOK, Web Search, Career Sites, SerpAPI Jobs) and ranks them
against a user profile. It currently works but returns thin, unreliable
data. Matcha 2.0 rebuilds it around a robust multi-backend data layer,
centralized filters, enrichment, and calibrated ranking. This session builds
ONLY Phase 0. The repo tree is clean (only revamp/ is untracked, which is
intentional). The venv is at /Users/rishi/Code/projects/matcha/venv.
