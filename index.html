# Why Matcha

Job boards show you every posting that matches a keyword. Matcha shows you only the ones that actually fit your profile.

🔀

Multi-source aggregation

LinkedIn, Indeed, Naukri, RemoteOK, Web Search, RSS, Google Jobs, and 200+ career sites — searched in parallel from one command.

🧠

Two-pass relevance engine

A confidence-weighted heuristic scores every job instantly; an optional AI pass re-scores your top candidates with real semantic understanding.

🎯

Central filter pipeline

Every job is normalized then filtered in a fixed order — quality, age, must-have skills, location, salary — with exactly how many jobs each stage cut.

🆓

Zero paid API requirements

All core sources work with no API keys. AI ranking and Google Jobs are optional upgrades with free tiers.

📄

Three-way profile entry

Upload a PDF resume, paste a LinkedIn URL, or type it manually. AI extracts your skills, title, and experience — saved once, reused forever.

🤖

Agent & automation ready

Structured JSON output, a bundled agent skill for Claude/OpenCode, and an optional MCP server — drive Matcha from scripts, cron, or an AI.

# Get started in 5 steps

From zero to ranked job matches in about two minutes.

  1. Install

    $ git clone https://github.com/rishikesh-sonawane/matcha.git
$ cd matcha
$ python3 -m venv venv
$ venv/bin/pip install -r requirements.txt
$ venv/bin/pip install -e .

    Requires Python 3.10+. A virtual environment is recommended on macOS (avoids LibreSSL segfaults).

  2. Create your profile

    $ venv/bin/matcha

    First run asks how to enter your profile — PDF resume, LinkedIn URL, or manual. Saved to ~/.matcha/profile.json, reused every run.

  3. Enable AI ranking (recommended)

    $ export MINIMAX="your-api-key"   # or run: venv/bin/matcha --configure
$ venv/bin/matcha

    Free providers: Groq, OpenRouter, Kilo Gateway — or AI_PROVIDER=local with Ollama/LM Studio, which needs no key at all. Without AI, Matcha ranks heuristically.

  4. Verify everything is healthy

    $ venv/bin/matcha doctor

    Per-source health plus an AI matching line: ok = fully wired, off = heuristic-only, warn = partial setup.

  5. Search — interactively or headless

    $ venv/bin/matcha                          # interactive TUI
$ venv/bin/matcha search -q "Platform Engineer" -l Pune -d 7 --json
$ venv/bin/matcha watch -q "Platform Engineer" -l Pune -d 7 --json  # only NEW jobs

# Everything it does

A quick tour of the surface area — details live in the README.

FeatureWhat it means for you
AI query expansionYour profile generates 3–5 diverse queries ("Platform Engineer" → SRE, Cloud Infra, DevOps Automation…) to widen the search surface.
Central filtersQuality → age → must-skills → location → salary, each reporting cuts. Provenance tags make low-confidence matches obvious.
watchOnly-NEW jobs since your last watch — the natural "anything new?" workflow, tracked in ~/.matcha/jobs.db.

Circuit breakersA flaky source is skipped for 30 minutes instead of failing every run. Health visible in matcha doctor.
Secrets at restAPI keys encrypted with fernet — never plaintext, no OS keychain dependency.

# Built for agents & automation

Matcha is a first-class citizen for AI agents, cron jobs, and scripts.

📦

Structured JSON everywhere

Every search returns {command, ai_used, source_counts, filter_summary, found_count, jobs[]} with per-job match_score, reasons, and apply URLs.

🎓

Bundled agent skill

$ venv/bin/matcha skill --install

Installs a bilingual SKILL.md so Claude/OpenCode can run health checks, ranked searches, and new-job watches for you.

🔌

MCP server

$ pip install -e '.[agent]'
$ venv/bin/matcha mcp

Exposes matcha_status and matcha_search tools to any MCP client.

⏰

Watch + cron

# every morning at 8am, diff new jobs vs yesterday
0 8 * * * cd ~/matcha && venv/bin/matcha watch -q "DevOps Engineer" -l Pune --json --output ~/.matcha/latest.json

# FAQ

QuestionAnswer
Do I need an API key?No — core search is keyless. AI and Google Jobs are optional with free tiers.
Can Matcha apply for me?No. Matcha opens the apply page — it's search + enrichment, never auto-apply.
How do I start over?venv/bin/matcha --new-profile, or rm -rf ~/.matcha for a full reset.
Where's the log?~/.matcha/logs/matcha.log (rotating 5 MB × 3).
What platforms?Python 3.10+, macOS and Linux (tested on macOS; CI covers 3.10–3.14 on Linux).
